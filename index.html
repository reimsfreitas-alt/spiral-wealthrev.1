Política de Privacidade – Spiral Wealth

Última atualização: 16 de junho de 2026

O Spiral Wealth foi desenvolvido para auxiliar usuários na organização de decisões financeiras e registros pessoais. Respeitamos sua privacidade e tratamos seus dados com transparência.

1. Coleta de Dados

O aplicativo pode armazenar informações inseridas voluntariamente pelo próprio usuário para funcionamento das funcionalidades do sistema.

2. Armazenamento

Os dados são utilizados exclusivamente para fornecer os recursos do aplicativo. Não comercializamos informações pessoais.

3. Compartilhamento

O Spiral Wealth não vende nem compartilha dados pessoais com terceiros para fins comerciais.

4. Segurança

Adotamos medidas razoáveis para proteger as informações armazenadas contra acesso não autorizado.

5. Direitos do Usuário

O usuário pode solicitar informações sobre seus dados ou solicitar sua remoção quando aplicável.

6. Alterações

Esta política poderá ser atualizada periodicamente para refletir melhorias do aplicativo ou exigências legais.
